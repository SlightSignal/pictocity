# Changelog

## 0.2.6

- Same-host ownership of physical data and document directories is acquired before recovery, store construction, font seeding and API admission. A cooperating duplicate desktop instance refuses visibly.
- Windows alias, concurrent startup and force-stop/reopen tests cover the named ownership scope. Older/direct/cross-machine writers and independently shared resource folders are excluded.
- This public source preparation updates setup/release documentation, test executable lookup and Node build lookup. Runtime implementation and the existing desktop package are unchanged; no public Windows binary is included.

## 0.2.5

- Agent font inventory preserves hosted family/face metadata, hashes and diagnostics alongside system-name strings.

## 0.2.4

- Multi-file downloads prepare one explicit ZIP Save link; recovery retains corrupt bytes and diagnostics, font descriptors use embedded metadata, and merged editing history preserves composed undo/redo.

## 0.2.3 and earlier
